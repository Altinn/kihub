Denne uken er tipset litt mer nisjerettet enn vanlig – primært for dere som bruker GitHub Copilot i hverdagen. Ikke alle i Digdir har tilgang til GitHub Copilot, så om du ikke gjør det, kan du trygt scrolle videre 😊

## 👉 Awesome GitHub Copilot

For dere som bruker GitHub Copilot: Dere har sannsynligvis allerede sett denne, men for de av dere som ikke har det – her er en gullgruve:

**[Awesome GitHub Copilot](https://github.com/github/awesome-copilot?tab=readme-ov-file)**

Dette er et community-drevet repository med over 14 000 stjerner, der utviklere fra hele verden deler ferdiglagde prompts, instruksjoner, agenter og konfigurasjoner for å få mer ut av Copilot.

Du finner blant annet:

- Spesialiserte agenter som integrerer med MCP-servere
- Kodestandarder som automatisk gjelder for filtyper du jobber med
- Oppgavespesifikke prompts du kan bruke direkte i Copilot Chat

Kort sagt: andres erfaring, pakket og klar til bruk.

Ha en god uke! 👋
