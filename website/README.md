# KI Hub Website

The public-facing site for KI Hub, built with [Astro](https://astro.build/) and
Designsystemet.

## Develop

Run these from the **repository root** (not from `website/`):

- `npm run website:dev` — generate catalogue data, then start the Astro dev server
- `npm run website:build` — full build (repo build + catalogue data + static site)
- `npm run website:preview` — preview the production build

## How data flows

Site content is generated by `eng/generate-website-data.mjs` from the
repository's agents, skills, instructions, and plugins into `website/data/`.
That data is a build artifact — **do not edit it by hand**; change the source
resources and rebuild.

## Structure

- `src/` — Astro pages, components, and content
- `data/` — generated catalogue data (build output)
- `design-tokens/`, `designsystemet.config.json` — Designsystemet theming
- `public/` — static assets
